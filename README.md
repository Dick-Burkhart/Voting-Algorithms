This respository contains a folder "common_code" of Fortran routines that are used by 3 projects used for the paper "A Clustering Algorithm for Proportional Representation".

The first project does preprocessing ("Pre_process") of the ballots from 40 electoral districts. 
The second project computes the proportional representation by clustering (PR_clustering). 
The third project tests the sensitivity of this clustering to changes in the domain of candidates (Domain_sens) .
